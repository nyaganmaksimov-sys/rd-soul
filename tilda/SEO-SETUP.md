# SEO для сайта SOUL в Tilda

## 1. Главный SEO-код

Файл `tilda/00-seo-head.html` вставляется **не в T123**, а сюда:

**Tilda → Настройки страницы → Дополнительный HTML-код для HEAD**

Он содержит:

- `<title>` — основной SEO-заголовок;
- `<meta name="description">` — описание страницы;
- `robots` — разрешение индексации;
- `canonical` — основной URL страницы;
- Open Graph для VK/Telegram/соцсетей и превью ссылок;
- Twitter Card;
- Schema.org `Restaurant`;
- Schema.org `ReserveAction` для бронирования;
- Schema.org `BreadcrumbList`.

## 2. SEO-настройки страницы Tilda

В **Настройки страницы → SEO** рекомендуется поставить:

**Title:**
`Ресторанный дом SOUL в Москве — ресторан, банкетный зал и караоке`

**Description:**
`Ресторанный дом SOUL в Москве на Сиреневом бульваре, 25А: ресторан, банкетный зал и караоке. Ужины, свадьбы, дни рождения, корпоративы и мероприятия. Бронирование столиков и залов.`

**URL страницы:**
`/`

Не добавлять в URL лишние слова, даты и параметры.

## 3. Структура заголовков

На главной странице должен быть **только один H1**:

`Ресторанный дом SOUL в Москве — ресторан, банкетный зал и караоке`

Остальные основные разделы — H2:

- Выберите свой формат
- Ресторан SOUL
- Банкетный зал
- SHUM — караоке и lounge
- Атмосфера SOUL
- Меню
- Отзывы гостей
- Забронировать столик или зал
- Контакты

H3 использовать только для карточек и подразделов внутри H2.

## 4. Важное для изображений

Все изображения, добавленные через стандартные Tilda-блоки, должны иметь понятный ALT. Не писать `image1`, `photo123` и т.п.

Примеры:

- `Ресторан SOUL в Москве — интерьер`
- `Банкетный зал SOUL на Сиреневом бульваре`
- `Караоке SHUM — интерьер и сцена`
- `Летняя веранда ресторана SOUL`

Не превращать ALT в список ключевых слов.

## 5. Локальное SEO

В тексте страницы естественно использовать реальные запросы:

- ресторан SOUL Москва;
- ресторан на Щёлковской;
- ресторан Сиреневый бульвар;
- банкетный зал Москва;
- банкетный зал на Щёлковской;
- караоке Москва;
- ресторан для свадьбы;
- ресторан для корпоратива;
- место для дня рождения в Москве.

Не повторять ключевые слова искусственно.

## 7. После публикации

1. Подключить домен `soul-rd.ru` в Tilda.
2. Проверить HTTPS.
3. Проверить, что `/` — единственная основная версия главной страницы.
4. Подключить Яндекс Вебмастер и Google Search Console.
5. Отправить главную страницу на переобход.
6. Проверить сайт через Lighthouse / PageSpeed.
7. Проверить Schema.org через Rich Results Test.
8. Проверить мобильную версию.

## 8. Не делать

- Не вставлять второй H1 в каждый T123.
- Не делать несколько разных `<title>` на одной странице.
- Не дублировать description в нескольких местах.
- Не использовать скрытый SEO-текст.
- Не набивать страницу ключевыми словами.
- Не ставить вымышленные отзывы, рейтинги или цены в Schema.org.
- Не добавлять несуществующие соцсети в `sameAs`.

## 9. Важный принцип

SEO-код хранится отдельно от визуальных T123-блоков. Поэтому дизайн можно менять в GitHub, не ломая мета-теги, Schema.org и техническую оптимизацию страницы.
